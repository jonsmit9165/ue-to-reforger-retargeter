# ⚔️ UE to Arma Reforger Animation Retargeter

Автономная программа для автоматического пакетного переноса анимаций со скелетов **Unreal Engine (UE4 / UE5 Mannequin)** на скелет **Arma Reforger (Enfusion Engine)**.

## ✨ Возможности
- 🎯 **Точный перенос костей:** автоматический маппинг более 60+ костей (руки, ноги, фаланги пальцев, плечи, таз).
- 🧬 **Умный позвоночник:** плавная интерполяция 3 костей UE (`spine_01..03`) в 5 костей Reforger (`Spine1..5`).
- ⚡️ **Пакетная обработка:** конвертация сотен анимаций за раз в 1 клик.
- 🖥 **Удобный GUI:** современный темный интерфейс на CustomTkinter с выбором файлов и папок.
- 📦 **Zero-setup:** скрипты запуска для Windows (`run_windows.bat`) и macOS (`run_mac.sh`).

## 🚀 Быстрый запуск

### На Windows:
Просто запустите файл:
```cmd
run_windows.bat
```
*(Скрипт сам создаст виртуальное окружение и установит все зависимости при первом старте).*

### На macOS / Linux:
```bash
chmod +x run_mac.sh
./run_mac.sh
```

## 🛠 Структура проекта
- `main_gui.py` — графический интерфейс пользователя.
- `retarget_engine.py` — математический движок ретаргета и интерполяции вращений.
- `mapping.json` — конфигурация соответствия костей и параметров осей.
- `Start.fbx` — базовый скелет Arma Reforger.
